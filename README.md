# 🧠 Cortex AI — Student Retention Core Predictive Engine

Cortex AI is an enterprise-grade full-stack predictive analytics platform designed to analyze, track, and forecast student academic attrition and success vectors in higher education systems. Powered by an optimized Machine Learning baseline classifier and packaged inside a stunning cyberpunk-themed modern web dashboard.

---

## 🚀 Key Architectural Features
- **High-Performance ML Core:** Leverages a custom-trained and balanced Logistic Regression architecture achieving a stellar **91.60% validation accuracy**.
- **Futuristic Glassmorphic UI:** A premium, dark-mode cyberpunk dashboard built with full responsive layouts using HTML5, CSS3, and asynchronous Vanilla JavaScript.
- **Micro-Service Telemetry Diagnostics:** Displays real-time prediction toggles, active probability gauges, and dynamic operational risk indicators (Financial & Academic sub-domains).
- **Enterprise-Grade Database Operations:** Secures user identity management (Authorization/Authentication layers) via local storage nodes integrated seamlessly with secure MongoDB query clusters.

## 🏃‍♂️ Local Sandboxing & Deployment Guide

Follow these sequential steps to boot the local environment on **Port 3000**:

### 1. Initialize Virtual Environment Isolation
```bash
# Generate the sandboxed virtual environment shell
python -m venv venv

# Activate on Windows Shell:
venv\Scripts\activate

# Activate on Linux / macOS Terminal:
source venv/bin/activate
```

### 2. Configure System Dependencies Matrix
```bash
# Installs enterprise packages globally inside the isolated environment shell
pip install -r requirements.txt
```

### 3. Verify Local MongoDB Server Connection
Ensure your local database engine (MongoDB Community Server / MongoDB Compass) is active on the network interface:
```text
Default Port: mongodb://127.0.0.1:27017/
```

### 4. Boot the Production Server Engine
```bash
# Ignite the Flask Application Server Pipeline
python app.py
```

### 5. Access the Live Web Application Console
Open Google Chrome or any modern web browser suite and navigate to:
```text
http://localhost:3000
```
